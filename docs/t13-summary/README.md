# T13 tabletop rules: working summaries

These are working notes for understanding T13 and adapting it to an engine.
They are not a replacement for the rules, an authoritative interpretation, or
a claim that the current implementation supports the described mechanics.
The Author's clarifications take precedence over assumptions in these notes.

- [Rules source inventory](source-inventory.md): datasets, coverage and caveats.
- [Tabletop concepts and systems](tabletop-systems.md): an initial map of the
  game and its major relationships.
- [Adaptation and open questions](adaptation-questions.md): principles and
  questions to resolve before turning rules into engine behaviour.
- [Racing Ordeal investigation](racing-ordeal-investigation.md): tabletop
  resolution, existing code and a proposed simulation-to-T13 bridge.
- [Ship Descendants, Values and Yarn events](descendants-values-yarn-events.md):
  initial rules trace and proposed ship-system integration.
- [Ship Proficiency inventory](ship-proficiency-inventory.md): catalogue
  locations, candidate threads and unresolved loading and suitability issues.

The initial survey inspected the structure and introductory passages of all
54 entries in the main rules dataset and examined selected rules in more
detail. It did **not** fully review every entry, table, variant or interaction.
Expand these notes as each system is traced and checked against its sources.
